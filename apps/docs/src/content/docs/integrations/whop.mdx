GoPayLocal creates percentage promo codes in your Whop account and counts the payments that use them.

## Setup

<Steps>

1. **Get your Whop API key and account ID**

   In the [Whop dashboard](https://dash.whop.com), create an API key for your account with only these permissions:

   | Permission | Used for |
   |---|---|
   | `promo_code:create` | Creating the promo codes |
   | `promo_code:basic:read` | Listing them |
   | `promo_code:delete` | Deleting them |
   | `developer:manage_webhook` | Creating the webhook that reports redemptions, and removing it when you disconnect |

   You also need your account ID, which starts with `biz_`.

2. **Connect in GoPayLocal**

   In the GoPayLocal dashboard, go to **Integrations**, set the environment switch to **Live** or **Test**, and click **Connect** on the **Whop** card. Enter the API key and the **Whop account ID**.

   GoPayLocal checks the key with Whop before saving it, then sets up redemption tracking. **Test connection** on the card checks the key again later.

3. **Create a campaign**

   Create a campaign and choose **Whop** as its payment integration. When the campaign becomes active, GoPayLocal creates its promo codes in your Whop account.

</Steps>

## How Discounts Work

Each code is a percentage promo code:

```json
{
  "code": "GPL_PPP-IN30-K7QX",
  "account_id": "biz_xxx",
  "promo_type": "percentage",
  "amount_off": 30,
  "new_users_only": false,
  "one_per_customer": false,
  "promo_duration_months": 0
}
```

- Every code starts with `GPL_`. Whop promo codes can't carry metadata, so the prefix is how GoPayLocal recognizes its own codes. The banner shows the code as Whop stored it.
- Codes aren't limited to new users, one use per customer or particular plans, and have no expiry date.

## Applying the Code at Checkout

The customer enters the code on Whop's checkout. Whop's checkout API has no field for a promo code.

## Test Mode

Whop has a separate sandbox (`sandbox.whop.com`) with its own accounts and keys. Connect a sandbox key and account ID while the dashboard is on **Test**. Test campaigns then create their codes in the sandbox.

## Redemption Tracking

When you connect a key, GoPayLocal creates a webhook in that Whop account for `payment.succeeded`. Deliveries are checked with the webhook's signing secret.

A redemption is counted for the payment that first applied a GoPayLocal code. Renewals and plan changes that carry the code aren't counted again.

## Limitations

- Product import isn't supported for Whop. Create your products in GoPayLocal by hand.
- Codes carry the `GPL_` prefix.
